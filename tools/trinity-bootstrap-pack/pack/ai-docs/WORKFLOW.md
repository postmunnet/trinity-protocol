# Workflow — 5-step ritual

```
sss "<task>"   →  open session
   ↓
nnn            →  plan with estimates
   ↓
vvv            →  verify intent (5 evidence questions)
   ↓
gogogo         →  execute plan incrementally
   ↓
ddd            →  human gate (deploy / done)
   ↓
rrr            →  retro + memory update
   ↓
close          →  archive session
```

Never skip a step. The kernel will refuse out-of-order transitions.
