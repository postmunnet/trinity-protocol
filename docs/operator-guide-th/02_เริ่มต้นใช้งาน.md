# เริ่มต้นใช้งาน

รันจาก repo root:

```bash
bash .ai/cli/ai status
bash .ai/cli/ai lll
```

เริ่ม session:

```bash
bash .ai/cli/ai sss "ทดลอง Trinity ด้วยงานเอกสารเล็ก ๆ"
```

ตอบ `vvv`:

```bash
bash .ai/cli/ai vvv \
  --answer 1="สำเร็จเมื่อมี plan ที่ชัดเจน" \
  --answer 2="แก้เฉพาะ docs" \
  --answer 3="ห้ามแก้ source code" \
  --answer 4="มีไฟล์ plan และ acceptance" \
  --answer 5="scope อาจกว้างเกินไป"
```

ดูสถานะ:

```bash
bash .ai/cli/ai status
```

## อ่าน session capsule

หลัง `sss` จะมีโฟลเดอร์:

```text
.ai/sessions/<session-id>/
  THINK/
  SANDBOX/
  DO/
  CONTROL/
  CAPTURE/
  .state/
```

ถ้าหลงทาง:

- ดู `CONTROL/` เพื่อเข้าใจสถานะงาน
- ดู `THINK/` เพื่อเข้าใจ goal/scope/plan
- ดู `CAPTURE/` เพื่อดู evidence
- ดู `.state/session_state.json` เพื่อดู `graph_state`
- ดู `.ai/audit/events.ndjson` เพื่อดู truth log
