# Trinity Operator Guide

Language: [`English`](../operator-guide-en/00_README.md) | [`ไทย`](00_README.md)

คู่มือนี้เป็นเอกสารใช้งานแบบ practical สำหรับ Trinity v0.1.0 ไม่ใช่ spec
เต็ม และไม่ใช่ marketing page

เป้าหมายคือให้ human operator และ AI agent เข้าใจวิธีทำงานจริง:

- เริ่ม session อย่างไร
- ritual แต่ละตัวมีหน้าที่อะไร
- artifact truth คืออะไร
- audit/memory/state ต่างกันอย่างไร
- release gate ต้องทำอย่างไร
