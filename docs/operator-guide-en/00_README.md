# Trinity Operator Guide

Language: [`English`](00_README.md) | [`ไทย`](../operator-guide-th/00_README.md)

This is a practical operating manual for Trinity v0.1.0. It is not the full
spec pack and it is not a marketing page.

The goal is to help a human operator or AI agent understand how to work inside
Trinity:

- how to start a session
- what each ritual is for
- what artifact truth means
- how audit, memory, and state differ
- how the release gate works
